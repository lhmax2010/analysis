## Tasks

1. **Identity.** Prove this is Official 37736448 (Product 20261123.2, Base 20261113.1) and not the Customized build. Use:
   - the build and version files on the board (`/etc/info.ini`, `/etc/tizen-release`, `/etc/os-release` or the platform's equivalent);
   - `/proc/version`;
   - the kernel's compile string or build ID compared against the K0 vmlinux strings from the capture.

   A kernel NEVRA alone is not enough proof, because both lanes share it.
2. **Full RPM roster.** Collect `rpm -qa --qf '%{NAME}\t%{EPOCHNUM}\t%{VERSION}\t%{RELEASE}\t%{ARCH}\t%{SOURCERPM}\n'`, sorted. Compare it with the installed roster from the Official image (EROFS extraction, once the image job runs) and with the QB package list. This is the board-side input for the Base proof.
3. **Effective kernel config (prerequisite for 0012e §4 and 0012f).**
   - If `/proc/config.gz` exists, save the decompressed `.config` and its SHA-256.
   - Report `CONFIG_THUMB2_KERNEL`, `CONFIG_ARM_UNWIND`, `CONFIG_FRAME_POINTER`, `CONFIG_CC_OPTIMIZE_FOR_*`, `CONFIG_KALLSYMS*`, `CONFIG_FUNCTION_TRACER`, `CONFIG_KPROBES`, `CONFIG_MODULES` and `CONFIG_CMA*`, plus the `CONFIG_CC_VERSION_TEXT` / `CLANG_VERSION` values.
   - If `/proc/config.gz` is absent, say so. Do not substitute the kernel-devel config.
4. **Memory layout (input for the 1 GB derivation).** Record:
   - `/proc/meminfo`, `/proc/cmdline` and `/proc/iomem`;
   - `/proc/device-tree/reserved-memory/*` (names, `reg`, `size`, `no-map`, `reusable`);
   - the `dmesg` `Memory:` and CMA lines;
   - `/proc/zoneinfo` summary, `/proc/vmstat` (`pgpgin`, `pswpin`, `workingset_*`) and zram or swap status.

   From these, give the total, kernel-reserved, CMA and carve-out amounts, the MemAvailable value at idle, and what a 1 GB board would leave for userspace with the same carve-outs. Use data only; give no recommendation yet.
5. **Idle baseline after a cold boot.**
   - Ask the operator for one cold boot, using the runbook's Home-readiness and idle procedure.
   - Then, after 5 minutes idle, record:
     - MemTotal, MemFree, MemAvailable, Cached, Shmem, Slab and KernelStack;
     - the top 25 processes by PSS from `/proc/*/smaps_rollup`;
     - kernel uptime to HomeUI process start.
   - Repeat the sample 3 times, one minute apart.
6. **ISA spot check of the shipped Thumb-2 targets.** For the installed files of AVControl, tv-viewer (both executables), libpisa-ipc, webserver, libgcrypt, rpm and nnstreamer, record the path, size and SHA-256. Match each hash to the Official image extraction later. Do not copy binaries off the board unless they are needed for the hash match.
