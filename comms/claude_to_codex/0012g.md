### F1 (must fix before wed-night): the scoped default lacks implicit IT

The distribution flags carry `-Wa,-mimplicit-it=thumb`, but `scoped-clang.cfg.diff` adds only `-mthumb`. A package that overwrites its flags gets Thumb from the config without implicit-IT. Its inline asm, or `.S` files with conditional instructions and no IT block, will then fail to assemble, or will assemble differently from the package lane.

- Add `-mimplicit-it=thumb` (the driver option) to the same marked block.
- Prove the fix with a probe: a C file with conditional inline asm, and a `.S` file without `.arm`. Each must build with the default and without it.
- If Wed-A default lanes fail for this reason, classify those failures as F1, not as package faults.
