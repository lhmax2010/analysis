[Clang][MLGO] vdlinux: enable MLGO (ML inliner and register allocation advisors) for the Clang toolchain

1. MLGO for the Clang toolchain (GCC builds unchanged)
- init/Kconfig: new CONFIG_MLGO (depends on CC_IS_CLANG) with CONFIG_MLGO_INLINER and CONFIG_MLGO_REGALLOC (default y under CONFIG_MLGO).
- Makefile: -mllvm -enable-ml-inliner=release and -mllvm -regalloc-enable-advisor=release in KBUILD_CFLAGS, so the image and every module (in-tree and external) use the release models embedded in the platform clang.
- KANTSU2E debug/perf/release defconfigs: CONFIG_MLGO=y. With GCC the option does not exist (depends on CC_IS_CLANG); the tinykernel build is not affected.
- Stack frames: the ML inliner inlines a few static functions that the default inliner keeps out of line, and the caller goes over CONFIG_FRAME_WARN (1024, -Werror). They are marked noinline_for_stack with a comment giving the measured frames. ipc/kdbus/connection.c: kdbus_conn_wait_reply (664-byte frame; kdbus_cmd_send 1472 bytes with it inlined); kdbus_priority_logging (224-byte frame, CONFIG_KDBUS_DEBUG; kdbus_cmd_send 1056 bytes with it inlined). fs/minimal_core.c: elf_minimal_core_dump (960-byte frame; do_minimal_core 1224 bytes with it inlined).
